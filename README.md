# Portfolio de Yougbare Ahmed Boudnoma

## Aperçu
Portfolio personnel responsive en HTML, CSS et JavaScript, avec navigation mobile, animations légères et bascule français/anglais.

## Lancer en local
1. Extraire le dossier.
2. Ouvrir `index.html` dans un navigateur.
3. Pour un serveur local, ouvrir le dossier dans VS Code puis utiliser Live Server.

## Déploiement sur Vercel
1. Créer un dépôt Git et y placer `index.html`.
2. Importer le dépôt sur Vercel.
3. Aucun build command ni framework n'est nécessaire pour cette version statique.
